# 📖 Overview

The **CDAC LMS Project** is a modern Full Stack Learning Management System developed during the **CDAC GenAI Workshop**. It demonstrates frontend and backend integration, REST APIs, authentication, database management, and responsive UI design.

---

# ✨ Features

* 👤 User Authentication
* 📚 Course Management
* 🎓 Student Dashboard
* 👨‍🏫 Instructor Dashboard
* 🔐 Secure Login
* 🌐 REST APIs
* 📱 Responsive Design
* ⚡ Fast Performance
* 🧩 Modular Architecture

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/cdac-lms-project.git
```

## Navigate

```bash
cd cdac-lms-project
```

## Install Backend Dependencies

```bash
cd backend
npm install
```

## Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

# ▶ Run Project

### Backend

```bash
npm start
```

### Frontend

```bash
npm run dev
```
